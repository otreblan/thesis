\section{Benchmarks}

\pgfplotstableread[col sep=comma]{\subfix{benchmarks.csv}}\BENCHMARKS

% How do I cite the Julia simulator?

The benchmark consists on running multiple 3D simulations on the Julia CUDA simulator and FDTD Lucuma with the Vulkan backend where the only variation is the size of the simulation matrix.
The tests were executed on UTEC's HPC cluster Khipu on the \texttt{ag001} node, which has a NVIDIA A100 40 GB GDDR6, and by using Nsight Compute as the profiler.
